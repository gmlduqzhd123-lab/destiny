# 명운 (命運)

이름, 생년월일(양력), 태어난 시간(선택), 성별, MBTI로 보는 사주·궁합·운세·타로 웹앱입니다.
서버 없이 정적 파일만으로 동작하며, 입력 정보와 운세 일지는 브라우저(localStorage)에만 저장됩니다.

## 화면 구성

| 탭 | 내용 |
|---|---|
| 今 오늘 | 오늘의 십신(오늘 일진 × 내 일간), 연애·금전·직장 점수, MBTI 조언, 개운 요소, 고전 한 구절, 전화위복 풀이, 명운첩 카드 |
| 命 사주 | 사주 원국 8글자와 십신, 일간 캐릭터, 오행 밸런스, MBTI × 사주 교차 해석, 대운·올해·이달 운, 부적 |
| 緣 궁합 | 일간 오행·일지·띠·MBTI 궁합(100점), 궁합 초대 링크 |
| 星 타로 | 메이저 아르카나 22장, 원카드/3카드/연애 스프레드, 부채꼴 덱에서 직접 뽑기 |
| 記 기록 | 운세 달력(십신 도장), 연속 방문, 오늘의 평가·한 줄 메모 |

## 파일 구조

```
index.html
css/style.css
js/engine.js        결정론적 난수(같은 날 같은 입력 → 같은 결과)
js/saju.js          만세력 계산(절기 기반 년·월주, 60갑자 일주, 시주, 대운)
js/fortune.js       원국·오늘의 운세 점수 산출
js/compat.js        궁합, 초대 링크 인코딩
js/tarot.js         타로 덱·스프레드·리딩
js/journal.js       운세 일지
js/keepsake.js      명운첩 카드(Canvas) 렌더링·저장·공유
js/app.js           화면 전환, 탭, 렌더링
js/data/*.js        풀이 문장 데이터
```

## 계산 기준

- 양력 입력, 한국 표준시(UTC+9) 기준. 지역별 진태양시 보정과 과거 서머타임은 반영하지 않습니다.
- 년주는 입춘, 월주는 절입 시각(태양 황경)으로 바뀝니다. 절기 시각 오차는 수 분 이내입니다.
- 23시 이후 출생은 다음 날 자시(子時)로 봅니다.
- 재미로 보는 운세입니다.
