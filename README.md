# 별빛 나침반 (星光羅針盤)

이름, 생년월일(양력 또는 음력), 태어난 시간(선택), 성별, MBTI로 알아보는 **자기이해 기질 도감 · 우정 케미 · 상징 이야기 카드 · 마음 일기** 웹앱입니다.
상단 스위치 하나로 **🌱 학생용 모드**와 **🏫 선생님용 모드**를 즉시 전환할 수 있으며, 별도 앱 서버 없이 정적 파일로 동작하며 계산은 브라우저에서 수행합니다. 입력 정보는 ‘기억하기’가 선택되어 있을 때 기기의 `localStorage`에 저장됩니다(기본 선택, 해제 가능). 일기·방문 기록도 기기에 저장됩니다. 공용 기기 사용과 사용자가 직접 선택하는 결과·이미지 공유에 주의해 주세요.

## 🌱 학생용 모드 vs 🏫 선생님용 모드

| 구분 | 🌱 학생용 테마 (밤하늘 별빛 네이비) | 🏫 선생님용 테마 (서재 다크 골드) |
|---|---|---|
| **색감·분위기** | 청량한 밤하늘 네이비 & 따뜻한 별빛 골드 | 차분하고 품격 있는 전통 서재 & 클래식 골드 |
| **今 오늘** | 오늘의 별빛 뽑기, **우정·탐구·배움 지수**, 오늘의 작은 실천, 고전 명언과 생각 씨앗, 별빛 도감 카드(`夢·友·智·勇·誠·愛` 도장) | 오늘의 교단 점괘, **소통·활력·수업 지수**, 교단 힐링 미션, 아침 조회 한마디 활용 팁, 별빛 나침반 카드 |
| **星/命 기질** | 나의 시간 암호(네 기둥), **10가지 자연물 캐릭터**, 나의 강점과 더 자라날 점, 오행 밸런스, 별빛 응원 부적 | 사주 원국·기질 구조 + **교사용 학생 이해·상담·칭찬·행발 처방전** + **사회·과학·수학 수업용 전통 책력 원리(음력·24절기·60갑자·진태양시)** |
| **友/緣 케미** | **짝꿍·모둠 우정 케미**, 두 사람의 모둠 협동 약속 | **학생 모둠·관계 시너지 분석**, 모둠 역할 분담 및 갈등 예방 코칭 팁 |
| **繪/星 카드** | **상징 이야기·마음 카드** (`오늘의 별빛` / `이야기 3장: 시작·전개·결말` / `우정·교실`) | **교단 힐링 타로** (`원카드` / `3카드` / `관계·소통`) |
| **記 일기** | **별빛 마음 달력**, 오늘 하루 마음 날씨(`☀️ 신났어요 / ⛅ 평온했어요 / 🌧️ 토닥토닥`)와 한 줄 다짐 일기 | **교단·마음 일지**, 오늘 교실 하루 기록과 한 줄 메모 |

## 계산 기준

- 음력 생일은 한국천문연구원(KASI) 기준 음력표로 양력으로 바꾼 뒤 계산합니다. 음력 1900년 1월 1일 ~ 2050년 11월 18일을 지원합니다.
- 태어난 시간을 넣으면 태어난 지역(시·도 단위 경도)으로 출생 시각을 실제 태양 시각(진태양시)으로 보정합니다. 경도 차이(서울 −32분, 부산 −24분)에 계절에 따른 균시차(2월 중순 약 −14분 ~ 11월 초 약 +16분)를 더합니다.
- 보정할 때 당시 한국 표준시 이력(1908~1911년·1954~1961년 UTC+8:30)과 서머타임(1948~1951년, 1955~1960년, 1987~1988년)을 tzdb `Asia/Seoul` 기준으로 반영합니다.
- 년주는 입춘, 월주는 절입 시각(태양 황경)으로 바뀝니다. 절기 시각 오차는 수 분 이내입니다.

## 초대 링크와 개인정보

- 앱 초대는 쿼리나 해시 없는 앱 주소와 일반 안내 문구만 공유합니다. 이름·생년월일·성별·MBTI와 이 정보를 인코딩한 값은 포함하지 않습니다.
- 개인정보가 담겼던 이전 `?invite=` 링크는 더 이상 해석하거나 상대 정보로 불러오지 않습니다. 페이지 시작 시 주소에서 쿼리와 해시를 제거하고, 후속 요청에 페이지 주소를 전달하지 않도록 `no-referrer` 정책을 적용합니다. 업데이트된 서비스 워커도 이전 초대 쿼리를 네트워크 요청·캐시 키에서 제거합니다.
- 이미 공유된 링크·메시지·외부 로그는 이 수정으로 회수하거나 삭제할 수 없습니다. 기존 링크를 처음 열 때의 요청은 주소 정리 전에 호스팅 서비스에 도착할 수 있으므로 이전 링크를 다시 공유하지 마세요. 설치된 오프라인 앱은 온라인으로 다시 열어 업데이트해야 합니다.
- 자동 상대 정보 불러오기는 중단했습니다. 두 사람이 동의한 정보를 기기에서 직접 입력하는 케미 계산과 기존 저장 기록은 유지됩니다.
- ‘결과 공유’와 ‘이미지 공유’는 별도 기능이며, 사용자가 선택하면 이름·결과 등이 전달될 수 있습니다. 글꼴 등 외부 리소스 요청도 있으므로 모든 통신이 기기 안에서만 이루어진다는 의미는 아닙니다.

## 확인 방법

정적 사이트이므로 빌드 단계는 없습니다. `package.json`은 테스트에만 쓰이며 배포와는 관계없습니다.

- `npm test` — 만세력·음력·출생 시각 보정, 명렬표·모둠 편성, 도감 코드, 절기 시뮬레이터, 번역 데이터, 개인정보 보호 회귀 테스트 (Node 내장 테스트, 설치 불필요)
- `npm ci && npx playwright install chromium && npm run test:e2e` — 휴대폰 크기 화면에서 주요 흐름을 눌러 보는 E2E 테스트
- `npm run serve` — `http://localhost:4173`에서 로컬 화면 열기
- PR과 main 푸시마다 GitHub Actions(`.github/workflows/test.yml`)가 두 테스트를 자동으로 실행합니다.
