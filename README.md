# 명운 (命運)

이름, 생년월일(양력 또는 음력), 태어난 시간(선택), 성별, MBTI로 보는 사주·궁합·운세·타로 웹앱입니다.
서버 없이 정적 파일만으로 동작하며, 입력 정보와 운세 일지는 브라우저(localStorage)에만 저장됩니다.

## 처음 오는 사람도 쉽게

- 입력 전 첫 화면에서 오늘의 일진과 그 기운을 먼저 보여 줍니다.
- 생년월일은 양력·음력(윤달 포함) 중에 골라 넣을 수 있고, 음력은 양력으로 바꿔 바로 보여 줍니다. 궁합 상대도 음력으로 입력할 수 있습니다.
- 생년월일은 `19980101`, `1998.1.1`, `1998-01-01`, `1998년 1월 1일`, `980101` 모두 받고, 띠를 바로 확인해 줍니다.
- 성별·MBTI는 버튼으로 고르고, MBTI를 모르면 네 문항으로 간이 추정합니다. 궁합 상대는 MBTI를 몰라도 됩니다.
- 태어난 시간과 태어난 지역은 접어 둔 선택 항목입니다.
- 한 번 본 사람은 다음 방문 때 "오늘의 운세 바로 보기" 한 번으로 결과를 봅니다.
- 결과 첫 화면은 점통을 흔들어 뽑는 **오늘의 점괘**(대길·길·소길·평·신중)로 시작합니다.
- 십신·원국·일간·오행·대운 같은 용어 옆 `?`를 누르면 쉬운 풀이가 나옵니다.

## 화면 구성

| 탭 | 내용 |
|---|---|
| 今 오늘 | 오늘의 점괘, 오늘의 십신(오늘 일진 × 내 일간), 연애·금전·직장 점수, MBTI 조언, 개운 요소, 고전 한 구절, 전화위복 풀이, 명운첩 카드 |
| 命 사주 | 사주 원국 8글자와 십신, 일간 캐릭터, 오행 밸런스, MBTI × 사주 교차 해석, 대운·올해·이달 운, 부적 |
| 緣 궁합 | 일간 오행·일지·띠·MBTI 궁합(100점), 궁합 초대 링크 |
| 星 타로 | 메이저 아르카나 22장, 원카드/3카드/연애 스프레드, 부채꼴 덱에서 직접 뽑기 |
| 記 기록 | 운세 달력(십신 도장), 연속 방문, 오늘의 평가·한 줄 메모 |

## 계산 기준

- 음력 생일은 한국천문연구원(KASI) 기준 음력표로 양력으로 바꾼 뒤 계산합니다. 음력 1900년 1월 1일 ~ 2050년 11월 18일을 지원합니다.
- 태어난 시간을 넣으면 태어난 지역(시·도 단위 경도)으로 출생 시각을 실제 태양 시각(평균태양시)으로 보정합니다. 예: 서울 −32분, 부산 −24분.
- 보정할 때 당시 한국 표준시 이력(1908~1911년·1954~1961년 UTC+8:30)과 서머타임(1948~1951년, 1955~1960년, 1987~1988년)을 tzdb `Asia/Seoul` 기준으로 반영합니다. 1908년 이전 출생은 지역 시각 그대로 봅니다.
- 년주·월주는 보정한 실제 순간으로, 시주·일주는 보정한 지역 시각으로 정합니다. 균시차(진태양시)는 반영하지 않습니다.
- 지역을 '해외·모름'으로 고르거나 예전에 지역 없이 저장한 기록은 입력한 시각을 그대로 씁니다.
- 년주는 입춘, 월주는 절입 시각(태양 황경)으로 바뀝니다. 절기 시각 오차는 수 분 이내입니다.
- 보정한 시각이 23시 이후면 다음 날 자시(子時)로 봅니다.
- 재미로 보는 운세입니다.
